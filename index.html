🔄 Google Sheets Sync
Sync your task data to Google Sheets — access from any device, any browser. Uses Google Apps Script (free, no subscription).
Last sync: Never
📋 One-time setup (5 minutes):
1. Go to sheets.google.com → create a new Sheet → name it MohanTeamSync
2. Click Extensions → Apps Script → delete all code → click 📋 Copy Apps Script above and paste → Save (Ctrl+S)
3. Click Deploy → New deployment → Web app
4. Set: Execute as = Me  |  Who has access = Anyone → click Deploy
5. Copy the Web App URL shown → paste in the field above → set a secret key → Save Config
6. Click ⬆ Push to Sheets — all your data syncs to Google Sheets instantly ✅
